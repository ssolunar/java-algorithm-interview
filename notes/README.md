# 학습 노트

《자바 알고리즘 인터뷰 with 코틀린》 챕터별 학습 노트입니다.
새 노트는 [TEMPLATE.md](TEMPLATE.md)를 복사해서 시작합니다.

## 구성

```
notes/
├── TEMPLATE.md        # 챕터 노트 템플릿
└── chNN/
    ├── README.md      # 개념 정리 + 문제별 회고
    └── solutions/     # 직접 푼 Java 코드 (PN.java)
```

- 개념 정리와 문제 회고는 `chNN/README.md` 한 파일에 모읍니다.
- 직접 푼 코드는 `chNN/solutions/PN.java`로 저장합니다. 여러 번 풀었다면 `PN_v2.java`처럼 뒤에 붙입니다.
- 상태 표기: `⬜ 예정` · `🔄 진행 중` · `✅ 완료` · `🔁 재복습 필요`
